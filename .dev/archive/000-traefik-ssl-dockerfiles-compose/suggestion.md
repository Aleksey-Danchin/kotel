Это свежий проект. Нужно настроить базовый запуск проекта в dev режиме.

Разработка будет через docker compose. Для backend и front нужно поднять по docker container. Для стартовой настройки нужны dockerfile.

infra/docker - директива для dockerfile
infra/compose - директива для манифестов docker compose

Особенности:

1) docker container будет только средой запуска. Фактически разработка будет идти на хосте, в контейнеры только пробросим volume с соответствующими директивами разработки.
2) Относительное расположение директив должно быть совпадать с реальным расположением. Это нужно чтобы alias правильно работали в runtime и для подсказок в редакторе.
3) prisma - это отдельный подпроект в отдельной директиве. Так надо. Не нужно его переносить в backend или дублировать код в backend. Backend будет импортировать получившиеся исходники prisma при необходимости.
4) Сейчас настраиваем только чтобы docker compose запускался. Больше не нужно. Проверить, что все части работают и все. Тестировать взаимодействие не нужно.
5) Нужно поднять postgres 18 версии. Текущая версия в docker hub 18.3. + persistent volume
6) Нужно добавить traefik. /api -> backend. / -> frontend.
7) Нужно добавить в scripts 2 скрипта dev-start.sh и dev-stop.sh
