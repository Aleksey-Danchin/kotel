8) Добавим guard для проверки авторизованности пользователя. Сценарии использования:

```
@UseGuards(SessionGuard)
@Get('/some')
async method (@SessionUser() sessionUser: User) {
```

```
@UseGuards(new SessionGuard({strong: true}))
@Get('/some')
async method (@SessionUser() sessionUser: User) {
```

```
@UseGuards(new SessionGuard({strong: false}))
@Get('/some')
async method (@SessionUser() sessionUser: User | null) {
```
