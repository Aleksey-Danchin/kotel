# Scenario 001: Добавление сервера через OAuth popup

**Client:** web  
**Automated test:** `apps/frontend/e2e/auth/oauth-flow.spec.ts`

## Goal

Пользователь добавляет один или несколько серверов в текущую сессию через OAuth popup и подтверждает, что карточки серверов появились.

## Preconditions

- Запущен как минимум один backend-сервер и он доступен по URL.
- На сервере существует хотя бы один пользователь (root создан через setup).

## Steps

1. Открыть страницу `/session-test`.
2. Ввести URL сервера в поле "Add server".
3. Нажать "Add server" и дождаться открытия popup с формой входа.
4. Ввести валидные логин и пароль, нажать "Submit".
5. Убедиться, что popup автоматически закрылся.
6. Проверить, что в списке появилась карточка сервера с корректным URL.
7. Нажать "Check status" и убедиться, что отображается поле `sessionId`.

## Notes

- Вариант с несколькими серверами: шаги 2-7 повторяются для второго URL, после чего обе карточки должны быть видимы одновременно.
- Вариант с неверным паролем: в popup показывается ошибка "Invalid credentials", окно не закрывается автоматически и позволяет повторить попытку.
- PKCE и `state` используются в popup-потоке; `state` хранится в `sessionStorage`.
- Связанная документация: `docs/auth/oauth-flow.md`.
